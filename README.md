A hands-on project repository for exploring and experimenting with Flutter and its associated tools.

Overview
This repository contains various projects created to deepen understanding of Flutter, its widgets, and associated tools. Each project serves as a practical exercise, designed to reinforce different aspects of Flutter development.

Projects
1. namer_app
Description: The namer_app is the first project from the Flutter codelab series. It's designed to introduce you to the basics of Flutter through a simple application that generates and displays random word pairs. This project helps in understanding the fundamental concepts of widgets, state management, and UI design in Flutter.
